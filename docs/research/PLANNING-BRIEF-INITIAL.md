# Bluebell 产品规划审计输入

日期：2026-10-04。本文供第一轮独立审计使用，最终产品和实现约定以 [PRD](../PRD.md)、[DESIGN](../DESIGN.md)、[开发计划](../IMPLEMENTATION-PLAN.md) 为准。此文不是应用实现授权。

## 决策边界

- 后端目录只读；当前工作树优先于 HEAD、README 和 OpenAPI 的叙述。文件指纹见 BACKEND-FACTS。
- 用户指定 React、TypeScript、Vite、Tailwind、shadcn/ui、Lucide、openapi-typescript、openapi-fetch。
- 用户已否决蓝紫、绿红、黄色。提案只使用纯黑白灰，不以别的饱和强调色替代。
- 外部开源项目只提供交互与视觉证据，不提供 Bluebell 功能事实。
- 本轮只交付研究、PRD、DESIGN、静态视觉评审页、开发计划及两轮审计记录，前端应用编码需另行确认。

## 产品范围

中文社区论坛，覆盖匿名阅读、注册登录、社区导航、按新近/热度读帖、发帖、设置/取消投票、平铺评论和回复、删除自己的帖子/评论、退出。

不做搜索、关注、收藏、通知、私信、个人资料编辑、头像上传、编辑帖子、创建社区、管理员面板。列表没有正文和评论总数字段，因此不展示摘要、阅读量、评论数和活跃用户榜。

## 视觉方案比较

方案 A：双栏阅读工作区。左侧社区导航，右侧正文；社区介绍置于社区页顶部，可展开。列表每行保留一条窄票数列，正文和元信息形成稳定对齐。白底、雾灰外部背景，墨黑只用于关键操作和选中状态。

```text
品牌                    社区入口       发布讨论 / 登录
社区导航 184px    │ 当前范围与排序
                 │ 票数  标题
                 │       作者 / 社区 / 时间
                 │ 分页
```

方案 B：三栏信息板。社区导航、帖子列表、固定推荐栏。

```text
社区导航 │ 帖子列表 │ 推荐 / 统计 / 社区说明
```

选择 A。后端没有推荐、成员数或活跃榜，三栏会迫使界面堆放静态文字或臆造数据。特色集中于真实的“票数列 + 阅读对齐 + 回复引用线”，不用大标题海报、渐变、满屏同款卡片或装饰性编号。

色值候选：#FFFFFF 白、#F5F5F5 雾灰、#E5E5E5 分隔、#737373 控件边界、#595959 辅助字、#000000 墨黑。字体为系统中文无衬线正文，英文品牌采用本地 Space Grotesk 字体（保留许可证，缺失用 sans-serif），不让下载字体成为阅读依赖。

## 关键行为

1. 首页默认最新，与后端默认 time 一致；热门显式 hot。页面每页10项，URL保存排序和页码。
2. 社区目录只有 id/name；社区页再取 introduction/created_at，不为目录逐项请求详情。
3. 登录前可以阅读，点击写入操作才引导登录；返回后不自动提交或自动投票。
4. 访问令牌只在内存；刷新恢复会话。没有 /me，用户名只是本地显示提示，缺失时显示“已登录”；JWT sub 仅用于UI归属判断，服务端权限最终裁决。
5. GET vote 缺鉴权，不把返回0解释为未投票。默认不依赖它初始化选中态；明确三个动作“赞成 / 反对 / 取消投票”，只有本次 PUT 成功才标示所选。重新加载后方向未知，重复选择同一方向由后端保证不重复计票。票数来自重新GET详情。
6. 达到7天后所有投票动作关闭，包括取消和重复方向；用固定截止时间提示并以服务端409结果为准，不承诺过期方向恢复。
7. 评论按正序平铺，回复只引用目标。目标不在当前页时显示“回复评论 #ID”，不冒称已删除、不全量扫页拼树。当前页目标可以定位。
8. 发帖/评论失败保留草稿，不自动重试写请求。500和网络中断可能结果不确定，先提示查看最新内容，不直接声称未发布。
9. 成功和失败使用图标+文字+轮廓，不出现绿色成功、红色错误、黄色警告。

## 工程约定待审计

- React Router 用于URL；TanStack Query 用于有限的查询缓存和明确的失效，禁自动重试。其他状态用 React state 和小型会话存储。
- 同源代理处理Cookie和CORS；不要求修改后端。
- openapi生成类型来自前端快照，源码差异显式记录，不编造后端字段。
- 状态区分未登录、会话恢复中、已登录、认证网络故障；错误不能当成空列表。
- shadcn引入必要组件，覆盖包括 destructive/ring 在内的颜色语义变量，避免默认彩色泄漏。
- 关键验收：注册登录刷新退出、双标签轮换、204、缺失回复目标、7日截止、权限403、POST结果不确定、响应式与键盘焦点。
