# 参考图论坛改造验证

日期：2026-10-05。用户确认新 Implementation Plan 后，以[提供的论坛截图](../design/forum-reference.png)为视觉依据，替换水墨布局、字体与底色。当前设计见 [DESIGN](../DESIGN.md)，当前组件静态示例见 [评审稿](../visual-preview.html)。

## 实际变更

- 系统中文无衬线、浅灰页面底、白色12px圆角面板、黄色 Bluebell 字标、深色主按钮、150ms交互。
- 社区导航从左侧移到白色顶栏，内容区左主面板、右300px侧栏，间距24px，页面顶部留白由128px改为24px。
- 帖子行最小84px，标题18px；作者、净票、时间放在第二行，社区标签靠右。首页取消大标题区，排序/刷新/发帖进入同一工具栏；无障碍标题保留。
- 新增 `forum-sidebar.tsx`：真实账号信息、已有快捷入口，以及服务端热度排序前五帖。复用原公开热度列表缓存，票数和删除使用原更新路径；小屏卸载，不为隐藏侧栏请求。
- 详情、评论、投票、发帖、认证、错误与模态框同步恢复紧凑空间和正常字重。横向社区导航的键盘焦点放在滚动区域内，避免外轮廓被裁切。

当前源码没有新增头像接口、等级、积分、浏览量、列表评论数、收藏、通知、搜索或商城。最热不标“今日热门”，不按净票重排。
