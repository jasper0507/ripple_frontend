# 发布入口位置与配色验证

2026-10-05 用户直接要求降低发布入口视觉优先级，并移到帖子列表顶部。本轮替代上一轮侧栏蓝色发布按钮。

## 改动

- 首页、社区列表工具栏提供“发布帖子”，浅灰底 `#F3F5F8`、灰蓝文字 `#52627C`、描边 `#8490A0`；44px高，悬停使用浅色反馈。
- 桌面范围、排序和发布同行；手机范围在第一行，排序和发布在第二行。菜单入口沿用相同浅灰配色。空列表复用顶部入口，移除重复发布按钮。
- 删除侧栏发布模块与说明，侧栏保留热门讨论，去掉原发布／热门分隔线。
- 入口携带社区与排序来源，并保存列表位置；登录后社区预选、草稿恢复和返回行为不变。
