# Bluebell 最终视觉规划审核输入

用户最终范围：只重设计已经实现的 `bluebell_frontend01` 的 UI、UX 和视觉文档；允许所有颜色，明确不做无彩色。不修改前后端代码。本稿供最终独立复审使用，历史初稿见 [INITIAL](PLANNING-BRIEF-INITIAL.md)。

## 审核资料

1. [当前基线](CURRENT-BASELINE.md)：现有前端、最新后端、文件指纹。
2. [PRD](../PRD.md)：产品人员评审的页面、状态、目标与边界。
3. [DESIGN](../DESIGN.md)：现有文件映射、token、尺寸、交互和保护线。
4. [视觉评审稿](../visual-preview.html)：彩色、响应式、无接口静态示例。
5. [改造计划](../IMPLEMENTATION-PLAN.md)：原子任务及验收。
6. [首轮审计处置](../reviews/DELIVERY-REVIEW.md)：适用项、过时项和未验证项。

## 审核重点

- 是否保留既有六类页面、Markdown 正文、连续加载、返回位置、草稿和就地评论回显？
- 是否仅修改呈现，避免推翻认证 ADR、改接口或重建项目？
- 是否以当前后端为事实源，删除已经过时的七日投票限制？GET 本人投票仍不可靠，是否保持未知态？
- 彩色角色、视觉稿和 DESIGN 是否一致，且不是仅换一个按钮颜色？
- 320/390/768/1440、焦点、表单错误、长内容与状态是否有可执行验收？
- 代码事实、既有前端选择、本轮设计提案是否明确区分？
- 是否错误声称已跑真实接口、已截图验收或已完成独立终审？

最终独立审计需要检查此版本，不能沿用初期新建工程方案的通过意见。
