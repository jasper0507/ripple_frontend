## 契约与代码

- 快照与后端 OpenAPI 逐字一致，SHA256：
  `cbab064e051bebe3a070b13d75ceaf212d44929e52a59950fa9aedf50775a419`。
- 作者字段统一为 `author_username`，包括帖子、评论与回复引用。旧字段不会
  被当作新契约成功响应。
- 列表不返回票数；列表与热门讨论不逐帖请求详情补齐。投票成功只更新
  已缓存详情的票数，不给列表补字段、不改变列表顺序或自动重取热度列表。
- GET 本人投票方向需 Bearer，登录后查询；页面刷新后恢复登录并查询。
  0 显示“未投票或已取消”；加载或失败保持未知。旧七天截止、开关和错误分支已移除。
- 写入结果未知时不重放 PUT，清除旧方向后重新读取；成功读取只证明当前方向，
  不把丢失响应的写请求宣称为成功。
- 帖子分页依据 `page`、`page_size=10` 与 `total` 推进，短页和空页不提前结束；
  总数覆盖完即停止，非法或不安全的分页元数据不继续。评论保持原来的尾页规则。
- 正文上限 10,000 个字符、评论上限 2,000 个字符，以提交时去掉首尾空白后的
  Unicode 字符数计算；不使用 UTF-16 长度限制截断输入。超限不发请求，草稿保留。
