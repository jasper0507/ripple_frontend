# 帖子流与阅读布局验证

日期：2026-10-05。用户确认 Implementation Plan，列表评论数先省略。设计见 [DESIGN](../DESIGN.md)，当前组件静态示例见[评审稿](../visual-preview.html)。

## 实际变更

- 首页改为截图三行：标题与右侧社区；作者与相对时间；分别显示赞成／反对箭头和原始票数。社区取消胶囊底与边框。
- 顶部与列表工具栏不再提供刷新／发帖，工具栏只显示最新／最热。读取失败的重试及删除后的重新加载入口保留。
- 移除主内容外框、重复账号卡和热门排行表格；右侧保留浅边框发布入口与热门讨论，260px宽、两栏48px间距。
- 黄色品牌块改为小尺寸灰色文字字标；顶部社区使用柔和选中背景。按钮改为8px圆角和蓝色主要提交，回复、删除与取消操作弱化。
- 列表／热门时间按本地日历显示刚刚、分钟、小时、昨天、月日及跨年年份；详情和评论继续完整时间。列表 `time` 保留机器可读日期与完整时间提示。
- 详情和发帖改为居中单列，详情不挂载侧栏、不请求隐藏热门列表。详情标题、作者／时间、Markdown、投票、评论、引用、编辑区及确认弹层重新排版。
- 小于1024px的发布与账号进入菜单；小于768px社区也进入菜单。菜单发帖关闭弹层并保留来源社区、排序与滚动恢复。

## 可读性与静态稿

按sRGB相对亮度计算：辅助文字在白底4.93:1、页面底4.64:1；链接／主按钮白字5.43:1；输入边界在白底3.24:1、页面底3.05:1。输入区保留清晰边界，删除确认继续有危险色和对象说明。投票选中通过显式 `aria-pressed:` utilities 上色，避免Tailwind层级覆盖。

静态评审稿使用当前组件DOM和最终构建CSS生成，自包含、无外部请求，含游客／登录首页、社区、详情评论、发帖、登录注册和不存在页面。内容是明确示例，包含长标题、相对时间、Markdown代码／引用、回复与编辑区。表单、投票、删除不提交；页签与示例链接只用于切换排版，手机菜单交互需运行应用检查。

## 真实浏览器限制

本轮实测：`make dev DEV_PORT=5176` 监听返回 `EPERM`；Playwright CLI迁移临时缓存后仍启动失败；直接运行Chromium使用临时profile时返回 `setsockopt: Operation not permitted`。没有可用截图，不将DOM或静态稿视为像素布局验收。

仍需在可运行浏览器的环境验收320/390/768/1440px、200%文字缩放、长标题／代码块无整页溢出、菜单焦点锁定／Escape、触摸／软键盘以及真实后端交互。原有单JS chunk超过500kB的构建提醒仍存在，本次没有调整加载架构。
