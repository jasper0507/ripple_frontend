## 主要改动

1. 冷白阅读面、蓝色主操作、珊瑚色回复关联及统一语义反馈；去掉暖色背景网格，favicon与字标同步。
2. 桌面使用单份左侧社区导航，发布与账号集中于顶栏；手机菜单收纳社区与账号。列表显示明确标注的净票，标题作为独立链接，保留连续加载与来源恢复。
3. 正文和评论沿同一阅读列排布；Markdown图片仍只显示替代文字，原始HTML不执行。回复目标已加载时可跳到页内评论锚点。
4. 投票写入未确认时重置当前帖子及账号会话的个人方向缓存，重新进入页面仍是未知；PUT确认与统计刷新失败分别反馈，不从总票数推断个人方向。
5. 标题移除UTF-16的原生maxLength截断，按与后端一致的trim后Unicode码点显示计数和校验。标题错误不会连带误报已选社区，字段错误有ARIA关联和首错焦点。
6. 评论草稿恢复、取消回复保留正文、就地“刚发表的”回显保持原行为。发布成功后列表刷新失败不将清空的编辑区标成无效。省略可能过时的评论总数，避免新增数据同步逻辑。
7. 删除确认使用危险样式，默认聚焦取消；触发按钮保持挂载，以便关闭时恢复焦点。失败留在确认框，成功才执行既有删除路径。

## 模态实现调整

计划中的Radix Sheet/AlertDialog改为一个共享的原生`dialog`容器，基础控件仍使用已有shadcn Button/Input。现有依赖与离线缓存没有Radix Dialog，因此未新增依赖。

原生`showModal()`负责top layer、背景隔离及焦点约束；组件接入初始焦点、Escape、关闭回焦、忙碌时阻止退出、菜单在路由或桌面断点变化时收起。DOM测试验证了组件的焦点接线，未验证浏览器原生模态行为。

重点覆盖：
