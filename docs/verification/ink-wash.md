## 对比度与风格

| 文字/边界 | 宣纸底 `#f8f5f0` | 辅底 `#f3efe8` |
| --- | --- | --- |
| 墨色正文 | 12.84:1 | 12.18:1 |
| 辅助文字 | 5.54:1 | 5.25:1 |
| 操作/成功 | 6.03:1 | 5.72:1 |
| 回复关联 | 6.06:1 | 5.75:1 |

| 警示 | 6.12:1 | 5.81:1 |
| 控件边界 | 3.58:1 | 3.40:1 |

采用 sRGB 相对亮度计算，常规文字均达到 AA 4.5:1，控件边界达到 3:1。浅墨分隔线仅划分内容，不替代控件边界。代码检查无饱和配色、粗边框、粗字重、厚阴影、渐变、弹跳/旋转/脉冲动画、超大标题类或大圆角类。正常按钮有透明背景、700ms过渡；输入有透明背景与明确聚焦描边。
