# 构建分包验证

日期：2026-10-05。

## 变更与原因

原路由静态引入所有页面，帖子详情的 `react-markdown` 及解析依赖进入唯一的 JS 包，触发 Vite 默认的 500 kB 告警。

`src/app/router.tsx` 将 `/posts/:postId` 改为 `route.lazy`，按需加载 `PostPage`。直接访问详情时使用静态声明的 `hydrateFallbackElement` 显示「正在加载帖子页面…」，保留内容布局；分包加载失败交给原有路由错误边界。

## 构建与检查

`make build` 通过，包含 TypeScript 检查，构建不再出现 500 kB 告警。没有调整告警阈值、添加依赖或配置手动分包。

| JS 产物 | minified | gzip |
| --- | ---: | ---: |
| 修改前唯一包 | 595.58 kB | 186.79 kB |
| 修改后主包 | 446.24 kB | 141.19 kB |
| 修改后帖子详情分包 | 150.27 kB | 47.81 kB |

首页主包减少约 25.1%；访问详情仍需下载详情分包，不代表全部 JS 总量减少。

`make lint` 无错误，保留原有三条 `react-refresh/only-export-components` 警告，位于 `src/app/session.tsx` 和 `src/components/ui/button.tsx`。`make test` 的 14 个文件、221 项测试全部通过。

## 生产浏览器检查

使用 Vite 生产预览、真实 Chromium 与模拟 API，共八项检查通过：

1. 首页加载完成后，没有请求 `post-page-*.js`。
2. 点击帖子时请求一个详情分包，正常渲染 Markdown 标题与正文。
3. 返回列表使用已有缓存，不重新读取帖子列表。
4. 延迟详情分包后，直接访问详情地址显示加载提示，站点布局仍可见。
5. 放行分包后，加载提示消失，正文正常渲染。
6. 正常跳转与直接访问均无未捕获浏览器异常。
7. 主动中断分包请求后，显示现有「页面出错了」错误页与返回首页入口。
8. 从分包错误页可返回首页，列表正常显示。

本轮没有进行真实后端联调或部署；分包失败恢复通过主动中断资源请求验证。已有业务测试继续通过，后端代码未修改。
