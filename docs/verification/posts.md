## 用户行为

- 首页和社区页读取真实帖子。行内只显示标题、作者、时间、社区、赞成数和反对数。不显示摘要、评论数或本人投票方向。游客可以浏览，列表和详情请求不带 Authorization。
- 排序在 URL：没有 `order` 或 `order=time` 是最新，`order=hot` 是最热。其他值改回最新且不发给接口。热度只是一种排序。
- 每页 10 条。接近底部追加下一页。结束和下一页用响应里的 `page`、`page_size`（必须是 10）、`total` 和原始 `items` 长度，不用去重后的条数。同一 ID 只保留第一次出现的顺序。
- 列表键是 `['posts','list', 社区 ID 或 null, 排序]`，详情键是 `['posts','detail', 帖子 ID]`。都是公开查询，退出或换账号不清除。评论键预留 `['comments', 帖子 ID]`，投票键预留 `['votes', 帖子 ID, ...accountScope]`。
- 同一标签页从详情或发帖页返回时，保留已加载页和滚动位置。点帖子标题，以及在首页或社区页点「发布帖子」，都会记下这个位置。接着去了另一份列表，这个标记就作废，回到原来的列表从第一页顶部重建。切换排序、点「刷新」或浏览器整页刷新同样从第一页顶部重建。窗口聚焦、网络恢复和重新挂载不重取。切换筛选会作废尚未返回的旧页。
- 页码分页在并发写入时仍可能漏帖。按 ID 去重只去掉重复，不补漏掉的帖子，也不改成游标。删除后的暂停追加只处理已知的页码偏移。
- 正文用 react-markdown，不启用原始 HTML。图片只显示替代文字，不发图片请求。代码放在 `pre`/`code` 里，长行在代码块内横向滚动。
- 发帖走现有登录门。标题去掉空白后按码点计 1–128，正文去掉空白后不能空，社区必须在当前列表里。列表为空或读取失败时不能提交。提交中按钮锁定，写入不自动重试。成功只拿到 ID，不把新帖插进已加载列表；回到来源列表仍是旧顺序，主动刷新后才会出现。详情打不开是另一句说明，不把发帖判失败。成功回调用当时的登录身份比对：账号、会话或草稿对不上，或者人已经退出，就不清草稿、不跳转。
- 侧栏「发布帖子」只在当前页是首页或社区页时记下返回位置。来源地址也只保留列表：在详情里再发帖，沿用进来时的列表；没有列表来源就不带，返回和删除回到首页，而不是上一篇帖子。
- 草稿键 `bluebell:draft:{用户 UUID}:post`，存在当前标签页 sessionStorage。刷新和同一用户再次登录会恢复。其他 UUID 不读、不提交。放弃和与本次快照匹配的成功会清掉。账号、会话或草稿对不上时不清理、不跳转。结果未知时留下输入，并提示不要直接再交。
- 只有 `author_id` 等于当前用户 UUID 时显示删除。页内确认，不是浏览器弹窗。只有 204 算成功：从已加载列表去掉，丢掉详情、评论和投票查询，暂停来源列表和含有该帖的列表继续追加，回到来源或首页，并说明「帖子已删除。」403 留在详情并说明无权。404 说明「这篇帖子已经不存在。」，同样清缓存并暂停追加，但不说删除成功。暂停时的共同提示是「继续加载可能漏掉帖子。请刷新后再浏览。」网络或 5xx 说结果未确认，不自动重试，不从列表移除。
- 评论、回复、投票操作、本人方向、编辑帖子、列表摘要和评论数不在本模块。详情留下投票和评论的位置，并显示公开票数。`patchPostVotes` 按 ID 更新详情和已加载行，不重排、不重取。

## 真实接口与浏览器验证（2026-10-04）

环境：MySQL `127.0.0.1:3306` 与 Redis `6379` 已在监听，后端 `go run ./cmd/server`（`:8080`），Vite `127.0.0.1:5173` 代理 `/api`。浏览器为 playwright-cli 的 Chromium。库里原有四个社区；社区 1 在验证中超过 10 条真实帖子。使用账号 `postv5a` 与 `postv5b`。

| 项目 | 结果 |
| --- | --- |
| 游客首页 | 通过：行内是标题、作者、社区、时间和赞成/反对，没有评论数。视口足够高时自动请求第 2 页，16 条后显示「没有更多帖子」。游客 `POST /api/v1/refresh` 401 不挡住阅读 |
| 排序 | 通过：`/?order=hot` 按热度请求；`/?order=nope` 改回 `/` 且不把非法值发给接口 |
| 空列表与地址 | 通过：社区 4 显示「还没有帖子」。`/posts/0` 为「帖子地址无效」，`/posts/999999` 为「帖子不存在」 |
| 正文 | 通过：帖子 7 的代码块是 `fmt.Println("hello")`，页面没有 `img` 和 `script`，替代文字「不该加载的图片」在。投票和评论位置保留占位说明 |
